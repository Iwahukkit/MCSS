# MCSS
A HCF-Style Minecraft Screenshare plugin to use on your servers!

# How to use it

Use Maven 3 to build or just download from releases and
modify it through the config

config.yml:

```
# ==========================================
#        MCSS ScreenShare Config
# ==========================================

screenshare:
  ip: "ts.example.com" <---- Custom IP

```
